Can a tiny decision model that runs entirely inside your browser play a video game? Here, AI plays the game with WebGPU, no server needed.

What is this?

A night-time arcade game. A wizard walks a haunted graveyard and then six dungeon rooms, dodging drifting ghosts and trying to reach a penguin before they catch him. Seven levels, a score with near-miss bonuses, and a lantern that lights the way.

You can play it with the keyboard, or hand the controls to a System One model: a small network that is shown a short description of the scene plus eight possible directions, scores each option in one forward pass, and the game takes the winner. Nothing is generated token by token; the model can only choose from the options we give it.

Models you can watch play: Laya (typed decisions, via layaForWeb), Julia-1, Kev-0.6B browser-use and Decision Lab V3 run in your browser with ONNX Runtime Web or Transformers.js, and any decision model you serve with Ollama (/v1/systemone) can play too.

Why create this?

Typed-decision (“System One”) models are small, fast classifiers that sit between a rules engine and a chat model. Several open ones now ship with ONNX weights and a browser runtime, which raises a practical question: can they actually be loaded from a static web page, with no server, and are they good enough to drive a real-time game?

This project is a small, honest test of that. We took the open models we could find, ran each one on WebGPU or WebAssembly in the browser, recorded real decision points from the game, and scored every answer against a lookahead oracle. The results are measured, not claimed.
